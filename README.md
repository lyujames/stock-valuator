# 美股估值计算器

Python 负责取数和估值计算，浏览器页面负责展示和调参。三个流派：**巴菲特流派**、**成长股**、**GARP**。

## 运行

```bash
pip install -r requirements.txt     # 只有取实时数据才需要 yfinance
python server.py                    # 自动打开 http://127.0.0.1:8765
python -m unittest discover -s tests
```

页面右上角：输入代码（如 `AAPL`）点「获取数据」，或先载入示例体验。左侧参数改动后自动重算。
取到的数据缓存在 `data/cache/`（12 小时）。服务只监听本机。

## 结构

| 文件 | 作用 |
|---|---|
| `valuation/engine.py` | 全部估值逻辑（纯标准库） |
| `valuation/data.py` | yfinance 取数、字段映射、缓存、示例加载 |
| `server.py` | 本地 HTTP 服务（标准库） |
| `static/index.html` | 单页前端，无外部依赖，可离线 |
| `samples/*.json` | 5 个**虚构**示例公司，也是手动输入的数据格式参考 |

## 模型说明

**公司类型**由增速和盈利自动判断：金融股 / 亏损 / 高速成长（≥25%）/ 中速成长（10%–25%）/ 成熟稳健（<10%）。类型决定三个流派在综合结果中的权重，例如成熟股以巴菲特流派为主，高增长股以成长股为主；亏损公司不给内在价值，只给参考指标；金融股改用 ROE 驱动的合理市净率。

- **巴菲特流派**：质量分（ROE、毛利率稳定性、FCF/净利润、资本开支强度、ROIC、负债等）+ 所有者收益 DCF。所有者收益 = 净利润 + 折旧摊销 − 维持性资本开支，维持性资本开支近似取 min(资本开支, 折旧摊销)；增速取保守上限（默认 10%）。格雷厄姆数、盈利收益率作参考，不计入估值。
- **成长股**：多阶段 FCF DCF（高增长期 → 线性衰减 → 永续）、未来 PE 回推；附反向 DCF（市场隐含增速）、Rule of 40、EV/营收。
- **GARP**：PEG、前瞻 PEG、林奇比率；合理价 = 最新 EPS × (合理 PEG × 增速%)，PE 限制在 5–40 倍。增速低于 8% 时不计入综合，高于 35% 时权重减半。
- 每个模型给悲观/基准/乐观三档（增速 ∓Δ、折现率 ±1%）。判断规则：价格 ≤ 价值 ×(1−安全边际) 为低估，≤ 价值 × 1.15 为合理，否则高估。

## 已知局限

- 增速默认来自历史 CAGR（回头看）。yfinance 能取到时用分析师预期，取不到时请在左侧填入自己的判断。
- yfinance 是非官方接口，字段名会变、偶尔限流；取数代码对每个科目都做了候选列表，但没有在真实网络下验证过，第一次用请先试一两只熟悉的股票并核对财报。
- 年报只有约 4–5 年，历史估值分位（PE/PB 百分位）暂未实现。
- 周期股、有大量股权激励的公司，结论要打折看待（页面会给出提示）。
- 仅供研究参考，不构成投资建议。
